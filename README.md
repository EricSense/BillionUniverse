# Billion Universe

One world. A billion lives. You have a place in it.

Billion Universe is a shared world you enter — not an application you use. You claim a room. You take a plot on an atlas among other lives. Districts are public places you walk into. The product is the universe itself.

## What it does

Gives a person a persistent place in one world: a room, coordinates, and four districts (Commons, Library, Workshop, Harbor). Organizations will later occupy territories in the same world instead of launching another app.

## What it solves

A billion people cannot share a feed. They can share a universe if presence is a place. The internet left everyone without a *where*. This puts one back.

## What it makes possible

A home that is not a profile. Schools and markets as land, not downloads. Scale as a design law from day one. A world that can outlive any one app.

## First 90 days

1. A door that works on a phone — arrive, keep a room.
2. A thousand claimed plots. The atlas feels occupied.
3. One real organization lives in a district instead of shipping an app.

## Run

```bash
npm install
npm test
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Claim a room, open the atlas, walk the Library.

Your person stays in `localStorage` on this device. Nothing is uploaded.
