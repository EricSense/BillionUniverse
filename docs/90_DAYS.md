# First 90 days

Build one capture rig, capture 10–20 real spaces, package a clean dataset, sell a pilot to one robotics or world-model startup.

| Window | Outcome |
| --- | --- |
| Days 1–14 | Walker v0 assembled, calibrated, universe 0001 shipped |
| Days 15–45 | 8–12 warehouses processed on a 24h clock |
| Days 46–70 | UB-01 frozen, two retail floors, a three-DC slice |
| Days 71–90 | One paid mid-size AMR / logistics pilot |

Do not lead with frontier labs. Lead with teams who need environment data this quarter and will not staff a capture crew.

Cash out the door is on the order of $21k (see `lib/kit.ts`). The library is the asset; the 90 days exist to make that library fundable.
