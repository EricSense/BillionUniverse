# Billion Universe

A **Universal AI system** — one mind, every domain.

Not a chatbot taped to one model. Faculties: sense, memory, reason, make, act. Memory lives on the device. Models can change; the system is the product.

The world is already powered by engines (connectivity, space, chips, superintelligence). This is the intelligence that can inhabit all of them.

```bash
npm install
npm test
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Ask what it is. Give it your name. Ask it to plan.
